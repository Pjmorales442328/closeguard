{# Trust strip on every page: where each number comes from, and what we do not claim. #}

Every number here is read, not typed

  • Run counts, events and the scene: this server's run state and its SHA-256 audit trail (verify it).
  • Benchmark figures: bench/results/latest.json and gate_off.json.
  • Blind test figures: bench/heldout/set_b/results.json, run once.
  • By construction (true in every run, enforced in code and tests): the gate imports only the standard library, fails closed, a memo cannot change an amount, the proposer cannot approve, nothing posts without a named human. Measured (true on our synthetic data only): every rate and count on the benchmark.
  • Posting: writer rows are read back through a separate read-only role and every row hash is recomputed.

What this does not claim

The data is synthetic. The memo filter is a tripwire, not a guarantee: it misses phrasings it has never seen (see the blind test). Model prices are unverified and the human baseline is still to be measured.
